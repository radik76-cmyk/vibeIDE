# Contributing to VibeIDE

Thanks for your interest! VibeIDE is a small, focused project — contributions are welcome.

## Quick Start

1. Fork the repo
2. Create a branch: `git checkout -b my-feature`
3. Make your changes
4. Test locally: `npx tsx app/src/index.ts /path/to/project`
5. Open a PR

## Guidelines

- Keep it simple. VibeIDE is intentionally minimal.
- One PR per feature/fix.
- Match the existing code style (TypeScript, no semicolons... just kidding, we use them).

## Ideas Welcome

If you're not sure where to start, open an issue to discuss before writing code. Some areas that could use help:

- Better Telegram markdown formatting
- Voice message support
- Document/file upload handling
- Multi-user support
